# FPS 验收与发布准备记录（本地）

## 结论与边界

**限定 UAC 原生 smoke 和重新执行的安全/桌面回归已通过独立审计；FPS-off 测量执行完成，但验收未全部通过，不能放行正式发布。**

候选版本为 `3.0.8.5-community.5`，本地对照基于 `8efa49e6b9227c5d6cb071e0e99b56d0b1f185c8`。候选仍使用已严格构建并核对指纹的 Test、Release 与后端测试程序集；本次另行重建不含 FPS 的同工具链 HEAD 基线。既有构建与功能修正轨迹见[本地候选验证](fps-local-candidate-validation.zh-CN.md)。
