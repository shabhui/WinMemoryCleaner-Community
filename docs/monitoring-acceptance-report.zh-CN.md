## 3. 安全进程操作

- 「释放工作集」与「结束进程」为两个独立按钮。结束前确认框含**名称、PID、未保存数据可能丢失**提示；取消执行路径不调用结束操作。
- 选择时的创建时间与操作时的进程身份使用**同一个原生句柄**校验；拒绝自身、关键和受保护进程；身份或保护状态无法确认时拒绝操作。
- 最终原生探针只操作本次验证自建的两个同名 64 MiB 子进程：取消后两者存活；只释放所选子进程工作集（记录为 84,160,512 B → 0 B，非应用分配内存归零）；确认结束只影响所选目标，另一子进程仍存活，随后单独结束另一验证子进程。
- `ProcessActionTests` 覆盖取消、拒绝、PID 复用、退出与权限失败。使用指南明确：释放工作集不保证降低 CPU/GPU 占用或提高游戏帧率。
- 本轮没有结束用户已有实例 PID 14400、游戏或其他既有程序，没有全系统工作集清空，也没有重置真实启动配置；测试构建与窗口测量使用隔离设置。
