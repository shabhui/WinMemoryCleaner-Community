# WinMemoryCleaner 社区版 · 资源监控与进程管理使用指南

本指南说明社区版新增的轻量资源监控、进程占用定位、安全进程操作与可选悬浮监控。原有内存清理、托盘、快捷键、设置、明暗主题与语言能力全部保留，使用方式不变。

**当前紧凑监控条版（2026-10-17）**：[新版便携 EXE](../build/monitoring-verification/compact-20261017/portable/WinMemoryCleaner.Community.exe)；[本次验证报告](compact-monitoring-report.zh-CN.md)；[实际窗口截图](../build/monitoring-verification/compact-20261017/preview.html)。旧版 EXE 与历史证据均保留，未覆盖。

快速使用：从旧版托盘菜单自行退出程序，再运行新版 EXE → **设置 → 悬浮监控** → 勾选需要的显示项（温度需单独勾选）→ 排列方式选横向/竖向 → 点击 **仅显示监控条**。点击托盘图标可重新打开主窗口和设置。程序是单实例，旧版未退出时不能把第二次启动当作新版验收。

## 运行要求

- Windows 10/11（64 位），已安装 .NET Framework 4.x（系统自带）。
- 程序需要管理员权限（与原版一致，用于内存清理与进程工作集操作）。
- 便携运行包为单个 `WinMemoryCleaner.Community.exe`，无需额外 DLL。

## 主界面概览（监控页）

打开主窗口即显示资源概览：

- **内存仪表**：横向主仪表显示物理内存占用比例，附已用/可用数值。
- **CPU / GPU 读数**：成对显示整机 CPU 使用率与 GPU 使用率（取最繁忙的物理显卡引擎），并标注数据来源（Windows GetSystemTimes / Windows PDH）。
- **温度**：CPU 与 GPU 温度分别显示，并注明来源（已有 ASUS CPU 传感器、NVIDIA 驱动 NVAPI 或 LibreHardwareMonitor）。**当没有可信来源时明确显示“不可用”及原因**，绝不使用 ACPI 区域温度冒充 CPU 温度，也不会显示虚假的 0°C。

### 刷新间隔

支持 **1、2、5 秒** 三档，默认 **2 秒**。可在设置页的监控分区修改。

### 关于"不可用"

监控坚持诚实显示：权限受限、驱动不支持、无传感器来源或读取失败时，主界面显示“不可用”及具体原因。监控条为避免撑大尺寸，预热/不可用项只显示 **—**；这不是 0，原因可在资源概览查看。进程页不可用值排在最后，不参与数值比较。

## 进程占用列表（进程页）

- 列出**当前可枚举的全部进程**，同名进程保留独立 PID 行。
- 列：名称、PID、内存、CPU（全机归一化）、GPU 使用率、显存占用（系统与驱动支持时显示）。
- **搜索**：支持按名称或 PID 模糊匹配。
- **排序**：点击列头可按内存、CPU、可用 GPU 指标升/降序排序，不可用值始终排最后。
- 权限受限或采样期间退出的进程不会导致列表崩溃，对应行会移除或标注不可用。

### 进程操作（两项独立操作）

选中进程后：

1. **释放工作集**：要求系统释放所选进程的工作集内存。这只是让系统把该进程的物理内存页换出/回收，进程继续运行；不保证降低其 CPU/GPU 占用，也不承诺提高游戏帧率。
2. **结束进程**：弹出确认对话框，明确显示**目标进程名称、PID 与"未保存数据可能丢失"警告**；只有点击确认才执行，**取消不执行任何操作**。

安全防护（内置，不可绕过）：

- 拒绝对工具自身、系统关键进程与受保护进程的操作。
- 身份校验与实际操作使用**同一个原生进程句柄**，杜绝同名进程与 PID 复用导致的误操作。
- 无法确认安全身份时拒绝操作并明确报错。

## 悬浮监控（默认关闭）

在设置页开启“悬浮监控”后，显示独立的**紧凑监控条**，不再使用固定宽度的大面板：

- **排列**：默认横向一行，CPU / GPU 的温度紧邻对应使用率；可切换竖向三组，选择会保存。全部显示项的本次实测为横向 **316×26 DIP**、竖向 **118×78 DIP**（系统 DPI 会影响实际屏幕像素）。没有外层大底框、常驻标题、阴影或长说明。
- **仅显示监控条**：点击同名按钮启用监控条并隐藏主窗口，保留托盘入口。不会改变原有关闭按钮偏好；保存为开启时，即使下次隐藏主窗口启动，也会恢复监控条。
- **不抢焦点**：开启时不激活；独立置顶，默认鼠标穿透，不影响下面的应用操作。
- **位置**：可选择显示屏与四个角落，也可点击“拖动定位”调整位置；位置保存，屏幕失效或坐标离屏时恢复到可见区域。横竖切换及语言切换不会重置已选布局。
- **显示项**：可分别勾选 CPU 使用率、GPU 使用率、内存、CPU 温度、GPU 温度。全新设置默认只勾选使用率和内存，保留已有用户选项，不擅自重置。
- 拖动定位时临时接受输入，短提示只在拖动模式出现；松开或 30 秒超时后恢复鼠标穿透偏好。
- 已通过普通窗口与无边框全屏窗口验证可见性与穿透性。**不覆盖独占全屏游戏、受保护应用或特殊反作弊环境**（不在保证范围内，也不做任何注入或绕过）。

关闭悬浮层并隐藏主窗口后，程序**停止无消费者的 CPU/GPU、温度与进程详情采样**，仅保留托盘内存显示与自动清理策略所需的最低限度监测（5 秒节奏）。重新打开窗口立即恢复采样。

## 温度来源说明

- **CPU 温度优先来源**：只读查询已安装 ASUS System Control Interface 驱动的 CPU 传感器 **0x00120094**。不安装驱动、不设置风扇/功耗/性能模式；不会把 ACPI thermal zone 温度当成 CPU 温度。本机 ROG Strix G834JZ / i9-13980HX 的最终 EXE 连续读到 **52→52→52→52→59°C**，主窗口隐藏后的监控条仍刷新。它是该硬件接口报告的 CPU 温度，不承诺与其他工具的核心最高温度完全一致。
- **CPU 备用来源**：LibreHardwareMonitor 的 WMI 接口，需要它以默认进程名称运行并实际提供 CPU 温度传感器。未检测到来源、驱动不支持或读取失败时如实降级，重试间隔最长约 30 秒；改名的便携版本可能无法自动识别。其他品牌硬件不保证 ASUS 来源可用。
- **GPU 温度**：优先使用已安装 NVIDIA NVAPI（标注对应显卡），LibreHardwareMonitor 作为备用。按显示项需求采样；恢复时可能短暂显示 —，不伪造 0°C。

- 原有"内存清理/优化"、托盘图标（内存百分比）、快捷键、自动清理策略、明暗主题、中英文切换全部保留。

## 常见问题

- **CPU 温度为 — / 不可用？** 在资源概览查看原因。已有受支持 ASUS 驱动时无需再运行外部软件；其他硬件或驱动权限受限时，可自行运行受支持的 LibreHardwareMonitor 并等待重试。没有可信来源时保持不可用，不安装新驱动强行出数。
- **GPU 使用率显示为不可用或等待中？** 首次采样需要两帧数据；虚拟显示适配器（如模拟器虚拟显卡）已被排除，仅统计物理显卡。
- **释放工作集后内存没降？** 工作集释放只影响所选进程的驻留内存；若进程仍在活跃分配，数值会再次上升。
- **仅显示监控条后怎样改设置？** 点击托盘图标重新打开主窗口。右上角“紧凑模式”是原清理窗口的精简模式，不等同于监控条独显。
- **运行新版却还是旧界面？** 两版共享单实例身份。请自行从旧版托盘菜单退出后再运行新路径；本次没有更改开机启动计划任务或覆盖旧 EXE。
