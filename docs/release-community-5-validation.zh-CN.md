# Community.5 发布验证记录

## 范围与发布条件

目标版本为 `3.0.8.5-community.5`，主程序与独立温度后端的程序集版本均为 `3.0.8.5`。本记录区分本地候选验证、正式 CI 构建与公开 Release；文档或版本号更新本身不代表发布完成。旧标签与旧资产不得覆盖。

整合内容包括优化进度及请求入队前互斥、最小/紧凑窗口与主题可读性、操作结果语言切换、通知与采样刷新优化、p3 温度驱动提示、载荷瘦身和中英双语 README。没有修改系统内存清理算法、进程优先级默认值或共享驱动安装权限。

### 保留的失败与修正轨迹

- 临时运行器曾给 Desktop 夹具添加 NUnit 逐测试超时，改变执行线程并破坏 WPF Dispatcher 约束。改为保持单 STA、按夹具分进程，使用外层进程超时；未删除测试或放宽断言。
- PowerShell 包装器曾误读空退出码；最终运行器使用真实子进程返回码及 NUnit XML 双重校验。直接调用脚本时，也不再把未设置的 `$LASTEXITCODE` 当作验证失败。
- 对应源码锁仍标记 p1，实际载荷已为 p3；仅对齐载荷标识，未改变固定源码来源、长度和哈希。缺失的本地源码缓存从锁定上游恢复后再测试。
- 历史 p2 主窗口总私有内存门槛失败，以及 p3 未完成的性能项目，仍保留在各自历史报告中；不以文档整理或短时截图将其改记为通过。

## 隐私与分发边界

- README 保留中文与英文完整说明、语言跳转、风险提示、项目来源和许可证。必要的公开项目账号/署名与用户本机身份分开处理。
- 待提交文本已检查本机用户名、机器名、绝对路径、实际进程身份、个人配置与常见凭据模式。唯一 PID 命中是合成测试夹具，不是真实运行身份。
- 源码 ZIP 及嵌套档案已检查已知本机身份标记；仓库九张历史文档图片与上游逐字节一致。文本扫描不能替代图像及二进制检查。
- 本地开发主程序和后端含本机 PDB 路径，**不作为发布资产**。日志、截图、完整进程清单、原始报告与私有备份仅留本地，不进入提交或分发包。
- 正式产物只能来自现有 Community release build。发布前还必须检查实际 EXE、内嵌压缩载荷、构建元数据、便携 ZIP、对应源码 ZIP、校验文件与版本公告，不能仅凭 README 脱敏就宣称整个包通过。
- 本轮清理针对当前待发布内容，不改写已推送 Git 历史，也不承诺清除历史副本。
