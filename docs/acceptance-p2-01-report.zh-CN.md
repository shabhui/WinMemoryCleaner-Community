## 1. 总结：验收工作完成，候选未全部通过

**确定的硬性阻塞：默认主窗口的总私有内存超过正式基线 +10 MiB。**

- 统计包含宿主、温度后端和其他自有后代进程；不能改成仅统计宿主来判通过。
- 九个量化门槛中八个通过，唯一失败项为 `mainPrivateWithinBaselinePlus10MiB`。这不等于八项原目标全部满足。
- 本轮新运行 **710 项回归测试**，全部通过；最终窗口交互 **503 个断言**全部通过，其中 **419 个**是逐 PID 唯一性检查，并非 503 个独立功能测试。

## 4. 正式性能方法与结果

### 方法

- Windows 验证环境；具体系统构建号及硬件配置不公开。双方使用相同的 .NET Framework MSBuild/Csc 工具链 Release；预检记录工具链哈希。
- 实际产品窗口与资源由验证 App 托管；**双方均绕过生产启动、设置迁移和单实例处理，不代表完整生产冷启动测试**。
- 使用隔离注册表、`zh-Hans`、深色、14pt、默认 2 秒刷新；关闭自动清理、更新和快捷键，保留托盘内存显示。这些是固定测试条件，不是用户个人配置。
- 基线测 `tray/main`；候选测 `tray/main/process/overlay`。每状态预热 30 秒、测量 60 秒，共三轮，比较状态交替执行，第二轮反转顺序。另有进程页 30 秒预热 + 600 秒稳定性运行。
- 悬浮性能状态为开启默认显示项后隐藏主窗口；不代表“开启全部可选温度显示项”的最高配置长测。仅悬浮开启温度时的恢复另由功能交互验证。
- 每轮使用独立嵌套 Windows Job，计入宿主及全部自有后代（温度后端及 conhost 等）。累计 CPU 包括已退出后代；内存逐进程求和。计量 Job 不设置 CPU/内存限额或 breakaway。
- 平均 CPU = Job 累计内核/用户 CPU 时间差 ÷ 实际测量墙钟时间 ÷ 逻辑处理器数 × 100；不是逐秒 CPU 百分比的简单均值。私有内存先逐样本求总和，再取本轮中位数，最后取三轮中位数。
- 正式采样期间没有并行构建、其他测试或截图。背景整机 CPU 单独保留，不从应用 CPU 中扣除，也不声称系统背景完全静止。
- 独立复算核对 **19 次正式运行、1,678 条测量记录**：宿主/后代分量、PID 与创建时间、活动进程数、CPU 时间差、时长、最近秩 P95、真实记录数与条件哈希一致；正式运行无采样错误、绑定警告或 stderr，均正常退出。

方法及逐轮本地记录：`build/acceptance-p2-01/measurement-plan.json`、`performance/round-1/stage-results.json`、`performance/round-2/stage-results.json`、`performance/round-3/stage-results.json`（后三者相对同一证据根）。

生产实现的身份校验与实际操作使用同一原生句柄；拒绝自身/关键/受保护进程、退出、身份变化及权限失败由自动测试覆盖。真实 GUI 确认框验证选择取消，使用假执行器，未对用户已有进程调用真实释放或结束。
