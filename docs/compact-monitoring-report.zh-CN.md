## 本机真实温度来源与安全边界

机器：ASUSTeK ROG Strix G834JZ / i9-13980HX，32 逻辑 CPU，物理 NVIDIA RTX 4080 Laptop GPU + Intel UHD。

- CPU：已有 `\\.\ATKACPI` 设备，打开 access=0、share=3，使用状态 GET IOCTL `0x0022240C`；请求为 DSTS `0x53545344`、参数长度 8、固定 CPU ID `0x00120094`、零控制参数。只接受存在标志 `0x0001` 和 1–150°C，拒绝短响应、异常状态、0 和越界。
- 本机非管理员工具会话已能读取此驱动；没有改权限、安装驱动或发送风扇/功耗/模式指令。这是该驱动报告的 CPU 温度，不保证与核心最高温度/其他工具完全一致。
- ASUS 不可用时使用既有 LibreHardwareMonitor 备用路径。其他品牌硬件或不同驱动不保证 ASUS 接口可用。LHM 需要以默认名称运行并提供对应硬件温度。
- GPU 保留 NVIDIA NVAPI / LHM 路径。本次最终测量末帧为 CPU **58°C（ASUS）**、GPU **48°C（NVAPI / RTX 4080 Laptop GPU）**，是当时读数而非恒定温度。
- 失败关闭句柄并退避约 30 秒；停采/退出释放句柄。保留这一保守策略，未根据未复现的瞬时异常改变硬件查询频率。
